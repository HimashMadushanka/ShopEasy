**Project Name:** ShopEasy

**Technologies Used:** Python (Flask),JSON, HTML, CSS, JavaScript, MySQL, XAMPP Server 

---


## 📝 Project Overview

ShopEasy is a **fully functional e-commerce platform** that allows users to browse, search, and purchase products online. It includes a **user panel** and an **admin panel** for managing products, categories, orders, and user accounts.  

Built using **Flask** for the backend, **HTML/CSS/JS** for frontend, and **MySQL** for database management. Images are stored in `static/images` and user uploads in `static/uploads`.

---
## 🔧 Technologies Used

- Backend: Python, Flask
- Frontend: HTML, CSS, JavaScript, Jinja2 templating
- Database: MySQL
- Server: XAMPP (Apache + MySQL)
- Icons & Fonts: Font Awesome, Google Fonts
- Analytics: admin analytics
